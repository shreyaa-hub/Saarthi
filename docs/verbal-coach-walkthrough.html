Entry and account creation

A visitor can use the canvas and browse the library before deciding to register. Patients and parents join by code; clinicians register directly.

Patient walkthrough

The patient sees one list of work regardless of who sent it, completes it in the player, and their result flows back to both the clinician and the parent.

flowchart TD
  SI(["Patient signs in"]):::start --> MM["My Missions
everything assigned, from either source"]:::act

  CLIN[/"Assigned by clinician"/]:::src --> MM
  PAR[/"Sent by parent"/]:::src --> MM

  MM --> PICK{"Open an
activity"}:::dec
  PICK --> PLAY["Activity player
opens the canvas snapshot
taken when it was assigned"]:::act

  PLAY --> KIND{"Activity
type"}:::dec
  KIND -->|Interactive| RESP["Taps, types, and drags
on screen"]:::act
  KIND -->|Hybrid| MIX["On-screen work plus
hands-on practice"]:::act
  KIND -->|Printable| PRINT["Prints the worksheet
and completes on paper"]:::act

  RESP --> SUB["Submits"]:::act
  MIX --> SUB
  PRINT --> SUB

  SUB --> SCORE["Responses scored
and recorded"]:::act
  SCORE --> DONE["Marked complete"]:::act

  DONE --> PROG["Progress
accuracy trend · clinician notes"]:::act
  DONE --> NOTIFY(["Clinician and parent
notified"]):::endc

  MM --> MSGS["Messages
thread with their clinician"]:::act

Messaging and notifications

The communication layer running underneath every role, delivered live rather than on refresh.

flowchart TD
  subgraph THREADS ["Conversation threads"]
    direction LR
    T1["Clinician ↔ Patient"]:::act
    T2["Clinician ↔ Parent
separate from the child's thread"]:::act
  end

  SEND["Message sent"]:::act --> STORE[("Stored and published
to the realtime channel")]:::store
  THREADS --> SEND

  STORE --> LIVE["Delivered live to
the other party"]:::act
  STORE --> NOTE["Notification created"]:::act

  LIVE --> UI1["Thread updates
in place"]:::out
  LIVE --> UI2["Conversation list
reorders"]:::out
  LIVE --> UI3["Unread badge
increments"]:::out

  NOTE --> BELL["Notification bell
live, with unread count"]:::out

  EV1[/"Activity assigned"/]:::src --> NOTE
  EV2[/"Activity completed"/]:::src --> NOTE
  EV3[/"Clinician note added"/]:::src --> NOTE

  DROP{"Connection
dropped?"}:::dec
  LIVE --> DROP
  DROP -->|Yes| RECON["Reconnect reconciliation
missed messages fetched and merged"]:::act
  RECON --> UI1
  DROP -->|No| OK(["Thread stays current"]):::endc
